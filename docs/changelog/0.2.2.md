**2 commits** · Charles Lindecker

Version 0.2.2 is a scope correction: the `docker-images` provider is dropped from gup, on the grounds that locally pulled Docker images are workload artifacts rather than tools a user wants kept up to date. The Containers category shrinks to six providers, and the catalog, architecture doc and landing data are updated to match.

## Removed

- **providers:** Remove the `docker-images` provider (pinned Docker tags) from the registry, tests, landing data and docs — local images are workload artifacts, not tools to update; the Containers category now lists 6 providers ([`607580c`](https://github.com/LINDECKER-Charles/gup/commit/607580c))
