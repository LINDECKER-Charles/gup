# 0.1.1 — 2026-05-20

[Release notes](../releases/0.1.1.md) · [GitHub Release](https://github.com/LINDECKER-Charles/gup/releases/tag/0.1.1) · [npm](https://www.npmjs.com/package/@charles_lindecker/gup/v/0.1.1) · [Compare `0.1.0...0.1.1`](https://github.com/LINDECKER-Charles/gup/compare/0.1.0...0.1.1)

**27 commits** · Charles Lindecker, dependabot[bot]

gup 0.1.1 is a patch release centred on security hardening of the command runner and several providers (command-name allowlist, argv sanitizer barriers, CodeQL alert #12 remediation for the Docker Desktop probe), plus provider reliability fixes for semgrep, pip and wsl-dnf. It also introduces the project's Vite/React landing site under index/ with a GitHub Pages deploy workflow, enriches the npm package metadata (homepage, keywords, funding, files, os) and translates the README, CONTRIBUTING and docs/ to English. No breaking changes.

## Added

- **landing:** Add the Vite/React landing site under `index/` with its SEO assets (favicons, web manifest, robots.txt, sitemap, llms.txt) ([`4423d09`](https://github.com/LINDECKER-Charles/gup/commit/4423d09))

## Changed

- **landing:** Self-host the Geist and Geist Mono fonts via `@fontsource-variable` so the page no longer render-blocks on a Google Fonts request ([`f0137d5`](https://github.com/LINDECKER-Charles/gup/commit/f0137d5))
- **landing:** Tighten SEO metadata, drop deprecated schema markup and broken references, and stamp the sitemap `lastmod` at deploy time ([`b392716`](https://github.com/LINDECKER-Charles/gup/commit/b392716))

## Fixed

- **providers/security:** Upgrade semgrep with the Python interpreter that owns the `semgrep` binary on PATH instead of `pip install --user`, which left a shadowed copy reported as outdated forever; skip with a manual hint when no interpreter is found ([`9aa9131`](https://github.com/LINDECKER-Charles/gup/commit/9aa9131))
- **providers:** Await the `pip`/`pip3` availability check so the pip provider is detected correctly, and let wsl-dnf surface its `refresh` marker (count -1) instead of silently skipping the distro ([`bb44399`](https://github.com/LINDECKER-Charles/gup/commit/bb44399))
- **landing:** Resolve logo URLs in the nav and footer through Vite `BASE_URL` so they load under the `/gup/` base path ([`42909de`](https://github.com/LINDECKER-Charles/gup/commit/42909de))

## Security

- **security:** Turn the runner asserts into sanitizer barriers that return the cleaned value, reject NUL bytes in argv, and silence vetted warnings in the security ESLint config ([`e7c3ea5`](https://github.com/LINDECKER-Charles/gup/commit/e7c3ea5))
