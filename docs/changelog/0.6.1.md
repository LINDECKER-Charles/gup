# 0.6.1 — not yet published

[Release notes](../releases/0.6.1.md) · [Compare `0.6.0...0.6.1`](https://github.com/LINDECKER-Charles/gup/compare/0.6.0...0.6.1)

**10 commits** · Charles Lindecker

0.6.1 opens the feedback form in the browser on Windows. The Feedback view and `gup feedback` handed its address to `explorer.exe` unquoted, and explorer, which splits an unquoted argument on `,` and `=`, read the form's query string as a separator and opened the Documents folder instead. Every argument of a detached launch is now quoted whole on Windows, so an HTML report under a folder whose name holds a comma opens as well, where gup printed its path. The feedback service's production stack gets a subnet of its own on the shared VPS (deployment only, not part of the npm package), and the cycle starts with the record of the 0.6.0 publication. The fix went through `fix/open-form-in-browser`, merged into `chore/release-0-6-1` and to `main` with the release through [#134](https://github.com/LINDECKER-Charles/gup/pull/134).

## Fixed

- **core:** on Windows, the Feedback view's form and `gup feedback` open in the browser again, instead of the Documents folder. gup handed the address to `explorer.exe` unquoted, and explorer splits an unquoted argument on `,` and `=`: the form's query string (`?install=…&version=…`) cut it short. `launchDetached` now writes every token of the command line quoted whole, the program's own path included, and has Node pass it verbatim (`windowsVerbatimArguments`); a token it cannot quote — a `"`, or a final `\` — is refused by the argv barrier. The opener's comma refusal goes: an HTML report whose folder name holds a comma opens too, where gup printed its path ([`48758be`](https://github.com/LINDECKER-Charles/gup/commit/48758be), [#134](https://github.com/LINDECKER-Charles/gup/pull/134))
- **feedback:** the production stack's private network gets a fixed subnet, `10.232.1.0/24`, outside the pools Docker hands out: the shared VPS had used up all 31 of them, and the first `docker compose up` failed with "all predefined address pools have been fully subnetted" ([`d0919af`](https://github.com/LINDECKER-Charles/gup/commit/d0919af), [#133](https://github.com/LINDECKER-Charles/gup/pull/133))
