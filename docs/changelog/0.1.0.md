# 0.1.0 — 2026-05-19

[Release notes](../releases/0.1.0.md) · [GitHub Release](https://github.com/LINDECKER-Charles/gup/releases/tag/0.1.0) · [npm](https://www.npmjs.com/package/@charles_lindecker/gup/v/0.1.0) · [All commits](https://github.com/LINDECKER-Charles/gup/commits/0.1.0)

**46 commits** · Charles Lindecker

0.1.0 is the first public release of gup: a TypeScript CLI that scans and updates every package manager on a developer machine behind a single command. It builds the core architecture (provider interface, parallel scan registry, execa runner, interactive menu, list/update/doctor sub-commands), then grows coverage from 15 to 139 providers across OS, language toolchains, cloud, IaC, Kubernetes, containers, security scanners, IDEs, editor plugins, WSL and shell tooling, including a self-update provider. The range also introduces the security posture (Semgrep, gitleaks, CodeQL, audit-ci, security tests), CI and Dependabot, and the contributor documentation needed for the npm publish under @charles_lindecker/gup.
