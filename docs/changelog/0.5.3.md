# 0.5.3 — not yet published

[Release notes](../releases/0.5.3.md) · [Compare `0.5.2...0.5.3`](https://github.com/LINDECKER-Charles/gup/compare/0.5.2...0.5.3)

**16 commits** · Charles Lindecker

0.5.3 adds 17 popular terminal themes, taking the picker from 10 to 27 — 11 on a dark ground, 6 on a light one, each kept only when it looks like no other theme in the colour roles gup paints, and each passing AA as written — and the picker's list now scrolls to keep the cursor in view. A winget package whose manifest requires an install folder (Battle.net) no longer holds the batch at winget's question in the embedded terminal: every winget call refuses prompts, and the package ends as a skip that names the command to run. source-map-js goes to 1.2.2 for GHSA-68fv-2mgg-jv7q, a dev-only advisory that turned the `npm audit (audit-ci)` gate red on every branch. The three branches were reviewed as [#99](https://github.com/LINDECKER-Charles/gup/pull/99), [#100](https://github.com/LINDECKER-Charles/gup/pull/100) and [#101](https://github.com/LINDECKER-Charles/gup/pull/101), stacked on `chore/release-0-5-3` and merged to `main` with the release through [#102](https://github.com/LINDECKER-Charles/gup/pull/102); the cycle starts with the record of the 0.5.2 publication.

## Added

- **ui:** 17 terminal themes, picked by GitHub stars and kept only when they look like no other theme in gup's colour roles — dark: `ayu-dark`, `cobalt2`, `everforest`, `gruvbox-dark`, `kanagawa`, `monokai`, `nord`, `one-dark`, `rose-pine`, `solarized-dark`, `synthwave-84`; light: `catppuccin-latte`, `flexoki-light`, `gruvbox-light`, `papercolor-light`, `rose-pine-dawn`, `solarized-light`. Each starts from the theme's published colours and passes AA as written; the roles that had to move are named in the themes guide ([`859081d`](https://github.com/LINDECKER-Charles/gup/commit/859081d), [#102](https://github.com/LINDECKER-Charles/gup/pull/102))

## Changed

- **ui:** the theme picker's list scrolls to keep the cursor in view and a click lands on the theme under it; on a narrow panel the list takes half the height, so the preview under it keeps its contrast verdict ([`480ced8`](https://github.com/LINDECKER-Charles/gup/commit/480ced8), [#102](https://github.com/LINDECKER-Charles/gup/pull/102))
- **ui:** the picker lists gup's own themes, then the community themes on a dark ground, then those on a light ground, each group in alphabetical order ([`859081d`](https://github.com/LINDECKER-Charles/gup/commit/859081d), [#102](https://github.com/LINDECKER-Charles/gup/pull/102))

## Fixed

- **providers/os:** a winget package whose manifest requires an install folder (Battle.net) no longer holds the batch: the embedded terminal let winget read a reply, so it waited at "Specify the install root" until the package was skipped by hand — 15 minutes in one run. Every winget call now carries `--disable-interactivity`, and `0x8A15005F` ends as a skip that names the `winget upgrade --id <id> --location <folder>` to run, as `0x8A150042` did before the embedded terminal ([`f68551f`](https://github.com/LINDECKER-Charles/gup/commit/f68551f), [#102](https://github.com/LINDECKER-Charles/gup/pull/102))

## Security

- **deps:** source-map-js 1.2.1 → 1.2.2 for [GHSA-68fv-2mgg-jv7q](https://github.com/advisories/GHSA-68fv-2mgg-jv7q) (high: event-loop denial of service through indexed source-map section offsets). Dev-only, pulled by `tsup` → `postcss` and `@vitest/coverage-v8` → `magicast`; the `npm audit (audit-ci)` gate failed on every branch ([`a709469`](https://github.com/LINDECKER-Charles/gup/commit/a709469), [#102](https://github.com/LINDECKER-Charles/gup/pull/102))
