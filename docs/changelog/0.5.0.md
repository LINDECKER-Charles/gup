# 0.5.0 — 2026-10-04

[Release notes](../releases/0.5.0.md) · [GitHub Release](https://github.com/LINDECKER-Charles/gup/releases/tag/0.5.0) · [npm](https://www.npmjs.com/package/@charles_lindecker/gup/v/0.5.0) · [Compare `0.3.2...0.5.0`](https://github.com/LINDECKER-Charles/gup/compare/0.3.2...0.5.0)

**541 commits** · Charles Lindecker, dependabot[bot]

0.5.0 is the first version published since 0.3.2. [0.4.0](0.4.0.md) was prepared but never published, so 0.5.0 also ships its OpenTUI interface and its Node >= 26.9.0 floor; the compare view above starts at 0.3.2 for that reason, while this file lists the 541 commits after the last one [0.4.0](0.4.0.md) describes (`f1864a9`), up to the version bump. The 0.5.0 cycle was built on `chore/integration-0-5-0` in three waves of branches, folded here from their changelog fragments and merged to `main` through [#88](https://github.com/LINDECKER-Charles/gup/pull/88); two Dependabot groups followed. Updates started from the interactive app run inside it, each install live in an embedded terminal (the optional `node-pty`), with one UAC or `sudo` prompt for all the administrator packages; packages are picked by checking them, and Entrée never updates the row under the cursor. gup keeps a debug log and reads its activity history back — for display only — as a Journal view with charts, `gup report` and a self-contained HTML report. Chosen packages, never a whole provider, can be updated on a schedule by a short-lived `gup` the OS starts every 15 minutes. Ten themes hold every text to WCAG AA, custom colours included, and settings persist in `config.json`. Providers of another OS are greyed out and never probed. The landing site speaks eight languages; the provider tests run as contracts on a fake machine, with end-to-end suites on every CI leg; the documentation gains generated screenshots and diagrams. For scripts: `gup report` now writes HTML by default, and the menu's "Tout mettre à jour" and "Cible…" entries are gone. Related commits of several branches are folded into one bullet that lists their hashes.
