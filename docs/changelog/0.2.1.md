**17 commits** · Charles Lindecker, dependabot[bot]

gup 0.2.1 is a maintenance release with no functional change: every commit since 0.2.0 is a Dependabot bump. On the runtime side, commander jumps three majors (12 to 15) with no code adjustment required, while @inquirer/prompts and semver take patch updates; on the dev side, @types/node moves to 25 and the vitest/eslint/tsx toolchain takes patch and minor updates. The landing site build under index/ moves to Vite 8. Flags, JSON output and behaviour are unchanged.
