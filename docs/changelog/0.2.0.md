# 0.2.0 — 2026-05-28

[Release notes](../releases/0.2.0.md) · [GitHub Release](https://github.com/LINDECKER-Charles/gup/releases/tag/0.2.0) · [npm](https://www.npmjs.com/package/@charles_lindecker/gup/v/0.2.0) · [Compare `0.1.1...0.2.0`](https://github.com/LINDECKER-Charles/gup/compare/0.1.1...0.2.0)

**42 commits** · Charles Lindecker, Hoklims (@hoklims), dependabot[bot]

gup 0.2.0 makes long `update --all` runs survivable on Windows: admin-only Chocolatey packages are batched behind a single UAC prompt, wedged installers can be skipped with Ctrl+C or a per-install timeout, and polyglot packages (node, python, go…) owned by a toolchain manager such as nvm or pyenv are no longer offered for a conflicting upgrade. It also fixes Chocolatey reboot exit codes being reported as failures, git-based global installs, locally-built Docker images polluting the summary, and the opaque `gup update <provider>` error. The release closes every CodeQL alert raised by the elevation feature and moves tooling to ESLint flat config with grouped Dependabot updates.

## Added

- **elevation:** Batch admin-required packages (Chocolatey) behind a single UAC prompt via a hidden `__admin-batch` child (`Start-Process -Verb RunAs` / `sudo`); declining is reported as SKIPPED, `--yes` skips the prompt, and the child's outcomes payload is validated against the request ([`aaa775d`](https://github.com/LINDECKER-Charles/gup/commit/aaa775d), [`f99579e`](https://github.com/LINDECKER-Charles/gup/commit/f99579e), [#22](https://github.com/LINDECKER-Charles/gup/pull/22))
- **skip:** Add a per-install wall-clock timeout (default 1200s, via `--timeout`, `GUP_INSTALL_TIMEOUT` or the Options menu) and Ctrl+C to skip the current package (twice to stop the batch), with process tree-kill on Windows; updates are now dispatched one package at a time ([`909765a`](https://github.com/LINDECKER-Charles/gup/commit/909765a))
- **ownership:** Hide polyglot upgrades (node, python, ruby, go, rustc, docker, git) when the binary on PATH belongs to another owner (nvm, nvm-windows, fnm, volta, mise, pyenv-win, asdf, proto, uv…); packages whose binary is absent are kept ([`b3f23b3`](https://github.com/LINDECKER-Charles/gup/commit/b3f23b3), [`a860aad`](https://github.com/LINDECKER-Charles/gup/commit/a860aad), [#21](https://github.com/LINDECKER-Charles/gup/pull/21))
