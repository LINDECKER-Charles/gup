# 0.3.2 — 2026-08-09

[Release notes](../releases/0.3.2.md) · [GitHub Release](https://github.com/LINDECKER-Charles/gup/releases/tag/0.3.2) · [npm](https://www.npmjs.com/package/@charles_lindecker/gup/v/0.3.2) · [Compare `0.3.1...0.3.2`](https://github.com/LINDECKER-Charles/gup/compare/0.3.1...0.3.2)

**15 commits** · Charles Lindecker

Version 0.3.2 adds 19 providers (MSYS2, Cygwin, Npackd, Fink, pkgin, Nix, pkgx, nvm, pyenv, swiftly, mint, vcpkg, Visual Studio, Git for Windows, .NET SDK, NuGet, PSResourceGet, Sparkle, xcodes), taking the registry from 134 to 153 entries. GitHub release lookups are hardened: the owner/repo slug is validated before any request and mint's git-URL host match is anchored, fixing a host-confusion bug. The landing page is rebuilt as a prerendered site whose version, provider count and Node floor are derived from the repository at build time, with the Pages workflow and Vite 8 minifier updated accordingly. No flag, command or output shape changed.

## Added

- **providers:** add 19 providers — `msys2`, `cygwin`, `npackd`, `fink`, `pkgin`, `nix`, `pkgx`, `nvm`, `pyenv`, `swiftly`, `mint`, `vcpkg`, `visual-studio`, `git-for-windows`, `dotnet-sdk`, `nuget`, `psresource`, `sparkle`, `xcodes` — growing the registry from 134 to 153 entries, each shipped with its test suite ([`84cc794`](https://github.com/LINDECKER-Charles/gup/commit/84cc794))
- **landing:** rebuild the site as a prerendered page whose version, provider count and Node floor are generated from `package.json` and the registry at build time (`sync-facts`, `prerender`, `stamp-static`, `verify` scripts) ([`01ce958`](https://github.com/LINDECKER-Charles/gup/commit/01ce958))
- **index:** mirror the provider registry in the site's provider catalog so the page lists all 153 providers grouped by domain ([`c281749`](https://github.com/LINDECKER-Charles/gup/commit/c281749))

## Fixed

- **providers/lang-other:** anchor the `github.com` host match when deriving the release slug from mint git URLs, so self-hosted mirrors no longer resolve to the public GitHub repository of the same name ([`4491273`](https://github.com/LINDECKER-Charles/gup/commit/4491273))
- **landing:** minify with oxc instead of esbuild so the Vite 8 build no longer fails on a clean `npm ci` ([`79e8ebc`](https://github.com/LINDECKER-Charles/gup/commit/79e8ebc))

## Security
