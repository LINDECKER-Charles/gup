# 0.3.0 — 2026-08-08

[Release notes](../releases/0.3.0.md) · [GitHub Release](https://github.com/LINDECKER-Charles/gup/releases/tag/0.3.0) · [npm](https://www.npmjs.com/package/@charles_lindecker/gup/v/0.3.0) · [Compare `029e2a0...0.3.0`](https://github.com/LINDECKER-Charles/gup/compare/029e2a0...0.3.0)

**32 commits** · Charles Lindecker, dependabot[bot]

0.3.0 makes gup genuinely cross-platform: four new macOS providers (Homebrew formulae and casks, Mac App Store, MacPorts), brew/apt/dnf install-source detection so package-manager-owned binaries are no longer hidden from the scan, and JetBrains/Eclipse discovery on macOS. It raises the floor to Node >= 22.13, fixes a stale hardcoded `--version`, mojibake in the bun and winget parsers, Windows 8.3 short paths in the runner and the broken Vite 8 landing build. CI now runs on Windows, macOS and Linux with a lint gate that enforces the size and complexity limits, after a repository-wide refactor to meet them.

## Added

- **core:** Add `brew`, `apt` and `dnf` install sources, resolving Homebrew symlinks to the Cellar and probing `dpkg -S` / `rpm -qf`, so package-manager-owned binaries stop being classified `manual` and hidden from the scan ([`8e08b50`](https://github.com/LINDECKER-Charles/gup/commit/8e08b50))
- **providers:** Add Homebrew formulae (`brew`), Homebrew casks (`brew-cask`), Mac App Store (`mas`) and MacPorts (`macports`) providers, bringing the catalogue to 134 ([`940893e`](https://github.com/LINDECKER-Charles/gup/commit/940893e))
- **providers:** Detect JetBrains and Eclipse installs on macOS (`/Applications`, `~/Applications`, Toolbox, Caskroom) and derive the other IDE providers' paths from the platform instead of assuming Windows ([`8349503`](https://github.com/LINDECKER-Charles/gup/commit/8349503))
- **providers:** Make `installHint` platform-aware via `pickInstallHint({ win32, darwin, linux, fallback })` and map Homebrew ids, so `gup doctor` prints a usable hint on macOS and Linux ([`51da62a`](https://github.com/LINDECKER-Charles/gup/commit/51da62a))

## Changed

- **deps:** Require Node >= 22.13.0 (Node 20 is EOL), build for `node22`, and bump execa 10, chalk 6, ora 9, p-limit 7, adm-zip 0.6, typescript 6, eslint 10.8, vitest 4.1.10; `@types/node` aligned on 22.x ([`82a4aa1`](https://github.com/LINDECKER-Charles/gup/commit/82a4aa1))

## Fixed

- **cli:** Read the version from `package.json` so `gup --version` and the menu header report the published version instead of a hardcoded, drifted `0.1.0` ([`c5c85f2`](https://github.com/LINDECKER-Charles/gup/commit/c5c85f2))
- **providers:** Repair double-encoded UTF-8 in the bun and winget parsers: `bun pm ls -g` trees never matched (zero packages detected) and winget's French end-of-table line went unrecognised ([`cee7245`](https://github.com/LINDECKER-Charles/gup/commit/cee7245))
- **core/runner:** Accept `~` in the command allowlist so Windows 8.3 short paths (`C:\PROGRA~1\...`, short-form `%TEMP%`) are no longer refused as unsafe command names ([`073bf0c`](https://github.com/LINDECKER-Charles/gup/commit/073bf0c))
- **index:** Use the `manualChunks` function form so the landing builds under Vite 8 / Rolldown; the `pages` deploy had been failing since the Vite bump ([`1025ffe`](https://github.com/LINDECKER-Charles/gup/commit/1025ffe))
