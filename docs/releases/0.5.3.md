# gup `0.5.3`

> **TL;DR** — **27 themes, and winget no longer waits on a question.** 17 popular terminal themes join the picker — Gruvbox, Nord, Solarized, Rosé Pine, Monokai, One Dark and more, on dark and light grounds — each from its published colours and each passing AA as written; the picker's list now scrolls. A winget package that asks for an install folder (Battle.net) used to hold the whole batch at its question in the embedded terminal: it now ends at once as a skip that names the command to run. A dev-only advisory in source-map-js is fixed.

`npm i -g @charles_lindecker/gup@0.5.3 --allow-scripts=node-pty`

---

## 🎨 17 popular terminal themes

The theme picker, **Options › Theme**, goes from 10 themes to 27 (or set `theme.id` in the settings file):

| Ground | New themes |
|---|---|
| dark | `ayu-dark`, `cobalt2`, `everforest`, `gruvbox-dark`, `kanagawa`, `monokai`, `nord`, `one-dark`, `rose-pine`, `solarized-dark`, `synthwave-84` |
| light | `catppuccin-latte`, `flexoki-light`, `gruvbox-light`, `papercolor-light`, `rose-pine-dawn`, `solarized-light` |

- **Picked by popularity, kept when distinct.** Families were ranked by the GitHub stars of their official repositories, one flavour per family and ground. gup paints 13 colour roles, so two themes that differ in an editor can look the same in gup: a candidate that painted closer to another theme than the closest pair gup already shipped was left out — Tokyo Night and Night Owl paint as `catppuccin-mocha`, Material as `nord`, Tomorrow Night as `kanagawa`.
- **AA as written.** Each palette starts from the theme's published colours; a role that falls short of AA on the background or the cursor row moves along its lightness only, hue kept, just far enough. The [themes guide](https://github.com/LINDECKER-Charles/gup/blob/main/docs/guide/themes-and-accessibility.md#themes) names the roles that moved and each theme's lowest contrast, and its gallery shows every theme.
- **A list that scrolls.** The picker's list keeps the cursor in view and a click lands on the theme under it; on a narrow panel the list takes half the height, so the preview under it keeps its contrast verdict. The order is gup's own themes, then the dark ones, then the light ones, each group alphabetical.

## 🪟 winget never stops on a prompt

Some winget manifests require an install folder — Battle.net's does. Before the embedded terminal, winget could not read a reply and failed at once, and gup turned that into a skip naming the command to run. Since 0.5.0 updates run in a terminal winget can read, so it waited at `Specify the install root` until the package was skipped by hand: 15 minutes in one real run, with the rest of the batch behind it.

Every winget call now carries `--disable-interactivity`. The package ends in seconds as a skip:

```text
winget needs an install folder gup cannot choose: run winget upgrade --id Blizzard.BattleNet --location <folder> in a terminal
```

Installers' own prompts are untouched: those still answer in the pane.
