# gup `0.6.1`

> **TL;DR** — **The feedback form opens in your browser on Windows.** In 0.6.0, Enter on the **Feedback** view and `gup feedback` opened the Documents folder instead of the form: `explorer.exe` cut the form's address at its query string. gup now hands every address and path to `explorer.exe` quoted, so the form opens prefilled with your install ID, and an HTML report under a folder whose name holds a comma opens too. macOS and Linux were not affected; nothing else changes.

`npm i -g @charles_lindecker/gup@0.6.1 --allow-scripts=node-pty`

---

## 🪟 The feedback form opens in the browser

On Windows, gup opens a web page or a report through `%SystemRoot%\explorer.exe`, by its full path, never through a shell. explorer parses its own command line and reads `,` and `=` in an unquoted argument as separators. The form's address carries its prefill in a query string:

```text
https://lindecker-charles.github.io/gup/fr/?install=…&version=0.6.0&platform=win32#feedback
```

explorer stopped at the first `=` and fell back to the Documents folder.

- **Every argument quoted whole.** On Windows, the runner now writes the command line of a detached launch itself: each token between quotes, the program's own path included, handed to Windows as it is. explorer and the C runtime both read one argument, and the form arrives with its query intact.
- **Nothing that could break out.** A token holding a `"`, or ending in a `\` that would escape the closing quote, cannot be quoted so: the argv barrier refuses it before anything starts. Neither occurs in a Windows path or in an address gup builds, where `"` is percent-encoded.
- **Reports under a comma.** The opener used to refuse a report path holding a comma and print it instead. Quoted, it opens like any other.

Checked on Windows 11 against a page served on this machine: the form's address reaches the browser with its query intact, a report under `Doe, Jane=x\` opens, and no Explorer window appears.

## 🧪 Tests

**8515 tests in 391 files** on Windows (0.6.0: 8511 in 391). The runner's unit suite checks that a detached launch on Windows passes every token quoted, in Node's verbatim mode, leaves the argv to the OS elsewhere, and refuses a quote or a final backslash before spawning. An integration test starts a real detached process and reads back an argument holding `,`, `=`, `&`, a space and a `#`, intact.
