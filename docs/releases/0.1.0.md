# gup `0.1.0` — Initial public release

> Imported on 2026-08-22 from the [GitHub Release](https://github.com/LINDECKER-Charles/gup/releases/tag/0.1.0) body, which had no in-repo source. Reformatted only: the original was indented as a code block with an unclosed fence. Content unchanged.

`gup` (Global Updater) — **one command to scan and update every package manager on your dev machine**.

Stop juggling `winget upgrade`, `scoop update`, `npm -g outdated`, `pipx upgrade-all`, `cargo install-update`, `dotnet tool update`, `gcloud components update`, `terraform self-upgrade`, `kubectl krew upgrade`, `code --install-extension`… `gup` runs them all behind a single CLI.

## Highlights

- **139 providers** across 21 categories: OS package managers, language toolchains, cloud CLIs, IaC, Kubernetes, containers, security scanners, IDE extensions, editor plugins, WSL distros, shell prompts, and more.
- **Interactive menu** (default) with auto-scan, review, multi-select, target update, fast mode, provider filter.
- **Non-interactive mode** for scripts/CI: `gup list --json`, `gup update --all -y`, `gup update winget:Microsoft.PowerShell npm-g:typescript`.
- **`gup doctor`** — see which providers are detected on your machine + install hints for the rest.
- **Self-update** built-in (`self` provider) — `gup` updates itself.
- **Cross-platform**: Windows, WSL, Linux. Tested on Ubuntu + Windows × Node 20 & 22.

## Security

The shell-out surface is taken seriously — see [`SECURITY.md`](../../SECURITY.md):

- `execa` argv-vector everywhere, **no `shell: true`** (enforced by tests)
- All `fetch()` calls pinned to `https://` literals (Semgrep + custom ESLint rule)
- **CodeQL** `security-extended` + `security-and-quality`
- **Semgrep** (`p/typescript` + `p/nodejs` + custom rules)
- **gitleaks** for secret scanning
- **audit-ci** + **Dependabot** (weekly, grouped) for deps
- `eslint-plugin-security` ruleset

```powershell
npm run security   # audit + lint-security + tests/security
```

## Install

```bash
git clone https://github.com/LINDECKER-Charles/gup.git
cd gup
npm install
npm run build
npm link            # exposes `gup` globally
```

Requires Node ≥ 20. PowerShell or Bash. Compatible Windows / WSL / Linux.

## Quick start

```bash
gup                # interactive menu (default)
gup list --fast    # quick scan, skip slow providers
gup update --all   # update everything (with confirmation)
gup doctor         # what's detected, what's missing
```

## Known limitations

- Some providers are slow to scan (pwsh-modules, vscode-ext, JetBrains plugins) — use `--fast` to skip them, or `--provider <id>` to target specific ones.
- Out of scope: Windows Update / drivers, project-scoped lockfiles (Maven/Gradle/sbt/bundler), JetBrains Toolbox-managed IDEs.
- Some providers depend on admin rights (choco) or interactive sudo (wsl-apt/dnf/pacman). gup detects and reports cleanly instead of hanging.
