gup — Global Updater CLI

Une commande pour scanner et mettre à jour ~130 sources d'installation sur votre machine — winget, scoop, chocolatey, npm-g, pnpm-g, pip, pipx, cargo, helm, kubectl, terraform, dotnet tools, vscode extensions, JetBrains, pwsh modules et 115+ autres.

Installation

npm install -g @charles_lindecker/gup
gup doctor
gup list --fast
gup update --all -y

Pourquoi gup ?

Sur une machine dev, les binaires viennent de dizaines de sources. Aucun outil natif ne les couvre toutes : winget upgrade --all skip silencieusement les pinned, ncu -g ne voit que npm, chaque CLI cloud/IaC/K8s embarque son propre self-update. gup unifie tout derrière une CLI plus un menu interactif. Scan parallèle (pLimit=4), fail-soft, mode --fast, sortie JSON pipeable, ciblage chirurgical provider:package.
